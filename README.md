# Atividade Prática 2 — Página Pessoal

## Conceito

Atividade prática da disciplina de Programação Web I, com foco na estrutura básica do HTML e na utilização de suas principais tags.

## Objetivo

Desenvolver uma página pessoal utilizando HTML, aplicando conceitos fundamentais de estruturação de conteúdo, títulos, parágrafos, imagens, links e navegação entre páginas.

## Estrutura do projeto

-`ATIVIDADE 2/` — pasta contendo as subpastas: paginas/, com os arquivos HTML, e img/, com as imagens utilizadas.
-`Atividade 2 - Página Pessoal.pdf` — documento com o enunciado da atividade.

## Tecnologias utilizadas

- HTML5
